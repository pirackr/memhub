# Opt-in agent trials

Run only with explicitly available harness installations and credentials. For each Claude Code, OpenCode, or pi trial, record harness/model versions, scenario, status, tool-call count, mistakes, latency, completion, and final vault checks. Scenarios: conditional create; paged discover/ranged read; hash-protected edit; conflict reread/recovery; requested delete. Unavailable combinations are `untested` with a reason and null measurements. Agent latency is never mixed with storage timing.
